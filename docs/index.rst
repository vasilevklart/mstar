M* Python API Reference
=======================

M\* ("M-star") is a disaggregated, any-to-any multimodal inference engine. This site holds
the Python API reference generated from the docstrings in ``mstar/``.

The guides (installation, serving, supported models, clients and model authoring) are at
https://m-star-labs.mintlify.site.
